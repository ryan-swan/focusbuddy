# Build scripts

| Script | Purpose |
|---|---|
| `mkvault.py` | Regenerate the vault from the consolidated master document. Rewrites the generated trees only — `CLAUDE.md`, `Home.md`, `build/` survive. |
| `assemble.py` | Regenerate the single-file circulation copy from the vault. Run after editing notes so the circulation copy never drifts. |
| `genindex.py` | Rebuild Appendix A (requirement index); check ID uniqueness and dangling references. |
| `verify.py` | Integrity suite for the single-file edition: fences, Mermaid parse, anchors, section coverage, table columns, RFC 2119 usage. |
| `checklinks.py` | Verify every wikilink in the vault resolves to a note, and every anchor to a heading. |

`_index/*.json` and `_index/*.csv` are generated by `mkvault.py`. Do not hand-edit them.

## Typical loop

```bash
python3 build/mkvault.py      # rebuild vault from master
python3 build/checklinks.py   # 0 broken links required
python3 build/assemble.py     # refresh single-file edition
```
