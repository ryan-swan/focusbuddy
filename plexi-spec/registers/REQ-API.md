### PLX-API-001

Every platform capability **MUST** be reachable through the public API. No capability **MUST** be exclusive to the first-party interface (`[[REQ-UX#PLX-UX-091|PLX-UX-091]]`).

### PLX-API-005

APIs **MUST** be versioned. A breaking change **MUST** require a new version; prior versions **MUST** be supported for a published deprecation period of not less than 12 months.
