# §31 Core Philosophy

◀ [[S30 Domain Model]] · [[Part IV — Domain Model|▲ Part IV]] · [[S32 Canonical Entity Model]] ▶

---

The platform is built upon five layered concepts:

```mermaid
flowchart TD
    A[Desk] --> B[Objects]
    B --> C[Events]
    C --> D[Relationships]
    D --> E[Understanding]
```

Everything else is derived. Nothing bypasses these layers.
